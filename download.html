FAQ

Questions, answered.

Is Nodalis really free?

Yes. Every feature on every platform is free, with no account, no ads and no trial period.

Where are my notes stored?

On your device. On a computer you can point Nodalis at any folder and every note is saved as a plain .md file you can open with any editor. You can also keep an automatic backup in your own private GitHub repository.

Do I need the internet?

No. Nodalis works fully offline. You only need a connection to sync with GitHub, or the first time you read text from an image (OCR).

Can I move between devices?

Yes. Turn on GitHub sync in Settings on each device, or export a backup .zip and import it on the other device.

Windows or macOS says the app is from an unknown developer. Is it safe?

Yes — the warning appears because Nodalis is not yet signed with a paid publisher certificate. On Windows choose More info → Run anyway. On a Mac open System Settings → Privacy & Security and click Open Anyway next to Nodalis.

Why is there no App Store download for iPhone?

Apple only allows iPhone apps through the App Store. Until Nodalis is listed there, add it to your Home Screen from Safari — it opens full-screen and works offline like an app.

How do I update?

Download the latest version from this page and install it over the old one. Your notes stay exactly where they are.

I already use Obsidian. Can I switch?

Yes. Point Nodalis at your existing vault folder — notes, folders and [[links]] come straight across.
